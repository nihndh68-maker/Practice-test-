# Shreehari IELTS Practice

**Live Site:** [https://sh-practice-tests.vercel.app](https://sh-practice-tests.vercel.app)

A focused **IELTS Academic** practice platform by **Shreehari Education Consultant Pvt. Ltd.**

Practice Reading and Writing modules with a clean, modern interface designed for students preparing for the Computer Delivered IELTS exam.

---

## Features

### Reading
- **20 full Academic Reading tests** (T1 – T20)
- Complete passages with questions
- Practice under real exam conditions

### Writing Task 1
- Describe charts, graphs, tables or diagrams
- Target: **150 words** in **20 minutes**

### Writing Task 2
- Essay writing in response to a point of view or problem
- Target: **250 words** in **40 minutes**

- Clean and distraction-free design
- Mobile-friendly
- Fast loading (hosted on Vercel)

---

## How to Use

1. Go to the homepage: [https://sh-practice-tests.vercel.app](https://sh-practice-tests.vercel.app)
2. Choose a section:
   - **Reading** → Select any test from T1 to T20
   - **Writing Task 1** → Open available tasks
   - **Writing Task 2** → Open available tasks
3. Start practicing
